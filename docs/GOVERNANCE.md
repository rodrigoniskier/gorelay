# Governance and publication scope

The original application source allowlist is MIT, copyright (c) 2026 Rodrigo Niskier
Ferreira Barbosa. LICENSING.md and LICENSE-SCOPE.json are authoritative for this
scoped grant; the repository is not blanket MIT. The 49 historical visuals have
independent reuse rights reserved; only three selected visuals are present here.
Tests/scripts, configuration, documentation and third-party material are not
relicensed automatically by the project.

This is a curated public representation with a new history and GitHub noreply
authorship. The original local repository, audit logs, patches, excluded screenshots
and private engineering history remain preserved separately. Selection removes
private email/local-user/environment records instead of rewriting the original.
Copyright-name permission is not treated as consent for unrelated personal data.

Publication requires exact-content independent review, local regression, real
GitHub Actions success and a private security-reporting mechanism. No backend,
database or demo endpoint is exposed by publishing source. No paid resource,
executable release or production readiness claim is part of this project.
Future changes must retain evidence limits, privacy, rights and dependency review.
